Forensic Score Formula

The baseline score is calculated from multiple image-processing indicators.

Indicator Score Weight / Role
ELA {{ scores.ela_score }} 35%
Frequency Analysis {{ scores.frequency_score }} 25%
Edge Analysis {{ scores.edge_score }} 15%
Noise Analysis {{ scores.noise_score }} 15%
Histogram Analysis {{ scores.histogram_score }} 10% Supporting Feature
Copy-Move Detection {{ scores.copy_move_score }} Independent Evidence
Baseline Score {{ scores.baseline_score }} Weighted DIP Score
Final Score {{ scores.final_score }} Maximum Evidence Score

Baseline Score = (ELA × 0.35) + (Frequency × 0.25) + (Edge × 0.15) + (Noise × 0.15) + (Histogram × 0.10)

Final Score = Maximum of Baseline Score and Copy-Move Score.

A Copy-Move Score of 60 or above is treated as strong independent evidence for the POSSIBLE TAMPERING category.

Interpretation Notice

DigiForensics uses multiple Digital Image Processing measurements to produce a heuristic forensic score.

Copy-Move Detection searches for repeated image regions occurring at different locations. A strong result can increase the forensic assessment.

The score is not a definitive determination of whether an image was manipulated. Image format, compression, resizing, camera processing, image content and other factors can influence the measurements.
